# Storyboard — Reel R1

1. **0:00–0:03 — Hook**  
   “SEU CONTEÚDO” ocupa o topo. Uma tarja verde imprime “pode estar CERTO” sobre o quadro.
2. **0:03–0:06 — Tensão**  
   Palavras corretas se multiplicam como pôsteres de feed. O excesso é coberto por “E AINDA PARECER IGUAL”.
3. **0:06–0:09.2 — Virada**  
   “PUBLICAR MAIS” é riscado. “SER RECONHECÍVEL” entra pelo mesmo risco, maior e estável.
4. **0:09.2–0:11.6 — Método**  
   O quadro troca uma palavra por vez: IDEIA, LINGUAGEM, CONSTÂNCIA. Apoio: “clareza que se repete”.
5. **0:11.6–0:14 — Payoff**  
   “Você não precisa aparecer. Precisa ser reconhecido pelo que defende.” Identificação médica fecha o vídeo.

**Origem editorial:** tese observada no conteúdo de Daria Medric sobre competência e conteúdo correto não bastarem para criar percepção ou diferenciação. Estrutura, texto e visual foram recriados do zero.
